# บริบทการทำงานปัจจุบัน (Active Context)

หน้านี้ระบุถึงจุดมุ่งหมายในปัจจุบัน สิ่งที่กำลังทำอยู่ และสถานะล่าสุดของโปรเจคในขณะนี้

---

## 1. สถานะปัจจุบันของโปรเจค (Current Status)
- **ระบบเสร็จสมบูรณ์พร้อมใช้**: ปัจจุบันหน้าจอแดชบอร์ดแสดงผลสรุปและข้อมูลรายรับ-รายจ่าย ปันผล รวมถึงภาษีได้ครบถ้วน
- **ระบบแก้ไขเสร็จสิ้นล่าสุด**: 
  - **จัดโครงสร้างโปรเจคแบบ React + Vite มาตรฐาน**: โค้ดเดิมที่อยู่ในไฟล์ `App.jsx` แบบเดี่ยวๆ ได้ถูกแยกชิ้นส่วนอย่างเป็นระเบียบไปที่โฟลเดอร์ `src/components/`, `src/utils/`, และ `src/constants/` เพื่อให้สามารถดูแลรักษาและต่อยอดได้ง่าย
  - **เพิ่มระบบกราฟสรุปพอร์ต (Asset Charts)**: ผู้ใช้สามารถสลับมุมมองดูสรุปการลงทุนในรูปแบบกราฟ Donut Charts แบบ Interactive ได้ ครอบคลุมข้อมูลมิติต่างๆ เช่น หมวดธุรกิจ, ตลาด, ปันผล, ภาษี ฯลฯ
  - **เพิ่มการแสดงป้ายกำกับอันดับมูลค่าตลาดโลก (World Top 100 Rank Tag)**: แสดงอันดับมูลค่าตลาดโลก ถัดจากมูลค่าตลาดในการ์ดสินทรัพย์ (`StockCard`) และหน้าต่างบันทึกข้อมูล (`UpdateModal`)
  - **เพิ่มป้ายกำกับประเภทพอร์ต (Port Tag)**: แสดงข้อมูลกลุ่มพอร์ตการลงทุนข้างๆ ชื่อหุ้นในการ์ดสินค้า
  - **แสดงเปอร์เซ็นต์ราคาเปลี่ยนวันนี้ (Price Change Badge)**: เพิ่มป้ายแสดงการเปลี่ยนแปลงราคาในรอบวันเป็นเปอร์เซ็นต์ต่อท้ายราคาหุ้นใน `StockCard` และ `UpdateModal`
  - **ยกระดับความพรีเมียมด้วยไอคอนตกแต่ง (Decorative Icons)**: สอดแทรกไอคอนสัญลักษณ์ทางฟังก์ชัน หน้าตัวเลขข้อมูลในรายละเอียดการ์ดหุ้นและส่วนเปรียบเทียบเป้าหมายในหน้าต่าง `UpdateModal`
  - **เพิ่มลิงก์ TradingView เชื่อมโยงหมวดหมู่ (Sector/Industry Navigation)**: ปรับแต่งป้ายหมวดหมู่ธุรกิจและอุตสาหกรรมใน `StockCard` ให้กลายเป็นลิงก์นำทางไปยังหน้าข้อมูลสถิติของหมวดหมู่นั้นๆ ใน TradingView
- **การทดสอบและรันโลคอล**: เซิร์ฟเวอร์สำหรับพัฒนาถูกรันค้างไว้ด้วยคำสั่ง `npm run dev` บนเครื่องของผู้ใช้เพื่อดูผลลัพธ์แบบเรียลไทม์ และระบบมีความเสถียรดี

## 2. สิ่งที่กำลังโฟกัสในปัจจุบัน (Active Focus)
1. **การจัดทำระบบบันทึกความจำของนักพัฒนา (Developer Memory Bank)**:
   - จัดตั้งโครงสร้างโฟลเดอร์ `memory-bank` เพื่อให้นักพัฒนาร่วม (AI หรือคน) เข้ามาอ่านทำความเข้าใจสถาปัตยกรรมและฟีเจอร์เด่นของโปรเจคได้ในทันทีโดยไม่ต้องงมค้นหาโค้ดใหม่
   - จัดทำแผนภาพและเอกสารรายละเอียดของฟังก์ชันการแปลงอัตราแลกเปลี่ยน การคำนวณเป้าหมาย และระบบเครื่องคิดเลข Popover
2. **การรักษาคุณภาพโค้ดดั้งเดิม**:
   - ป้องกันและระวังไม่ให้การอัปเดตไฟล์สไตล์ CSS และตัวแปรฟังก์ชันใน `App.jsx` ส่งผลกระทบกับความลื่นไหลในการดึงข้อมูลจาก Google Apps Script

## 3. แผนการหรือโอกาสในการพัฒนาต่อยอด (Future Improvements)
แม้ว่าเว็บแอพจะมีประสิทธิภาพสูงในปัจจุบัน แต่มีบางจุดที่สามารถปรับแต่งเพื่อยกระดับระบบให้ดียิ่งขึ้นได้ในอนาคต:

### A. การประมวลผลข้อมูลขนาดใหญ่ (Performance Optimization)
*   เมื่อข้อมูลพอร์ตขยายใหญ่ขึ้น อาจต้องใช้ `useMemo` เพิ่มเติม หรือสร้าง Virtualized List สำหรับการเรนเดอร์การ์ดหุ้นจำนวนมากๆ เพื่อป้องกันอาการหน่วงขณะสลับแท็บ

### B. การเก็บข้อมูล Cache และ Offline Mode
*   เพิ่มระบบ Cache ข้อมูลลงใน `localStorage` ชั่วคราวหลังโหลดข้อมูลสำเร็จ เพื่อให้ผู้ใช้สามารถเปิดเว็บขึ้นมาดูข้อมูลล่าสุดได้ทันทีโดยไม่ต้องรอ API โหลดใหม่ทุกครั้งเมื่อเปิดเว็บ (ลดเวลาโหลดครั้งแรกและใช้ทำงานออฟไลน์ได้ชั่วขณะ)
